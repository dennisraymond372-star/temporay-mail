Tempora Mail

A simple and modern temporary email website.

Features

- Generate a temporary email address interface
- Copy email addresses easily
- Refresh inbox interface
- Countdown timer
- Dark mode
- Responsive design for mobile phones and computers

Getting Started

1. Download or clone this repository.
2. Install dependencies using "npm install".
3. Start the development server using "npm run dev".
4. Open "http://localhost:3000" in your browser.

Deployment

This project can be deployed using "Vercel" (https://vercel.com).

Important Note

The current interface is a demo. Real email receiving requires an email service, a configured domain, and a secure backend.
